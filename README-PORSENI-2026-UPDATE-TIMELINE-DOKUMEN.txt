PEMBARUAN WEBSITE PORSENI 2026 — TIMELINE, DOKUMEN, DAN DENAH

Perubahan pada index.html:
1. Timeline pendaftaran Duta Pelajar diperbarui menjadi 1 November–6 Desember 2026.
2. Pembekalan Duta Pelajar dipisahkan sebagai agenda tersendiri pada 25 November 2026.
3. Puncak PORSENI tetap ditampilkan terpisah pada 25–26 Desember 2026.
4. Grafik timeline utama dan Timeline Duta Pelajar menggunakan satu jalur vertikal. Urutan dibaca dari atas ke bawah.
5. Ditambahkan bagian Denah Lokasi & Rincian Tempat pada tab Informasi sebagai tempat peta dan rincian venue setelah lokasi ditetapkan.
6. Tab Dokumen ditambah tautan unduh Contoh Berita Acara RAT (DOCX).
7. Tab Dokumen ditambah kartu Buku Pedoman Kegiatan PORSENI 2026. Kartu masih berstatus segera tersedia karena berkas pedoman resmi belum diberikan.

FILE YANG ADA DI PAKET:
- index.html: website utama versi terbaru.
- admin.html: portal panitia versi sebelumnya, tidak diubah pada pembaruan ini.
- Code_GS_PERBAIKAN_BYTE_GAMBAR.gs: backend versi sebelumnya, tidak diubah pada pembaruan ini.
- dokumen-contoh-berita-acara-rat.docx: contoh template berita acara RAT yang dapat diedit.
- favicon.ico, favicon-porseni.png, kop-porseni-resmi.png, logo-porseni.png, porseni-o-mark.png: aset visual.

CARA PEMBARUAN:
1. Unggah index.html versi terbaru ke hosting dan timpa file index.html sebelumnya.
2. Unggah dokumen-contoh-berita-acara-rat.docx ke folder hosting yang sama dengan index.html.
3. Pertahankan aset gambar dengan nama file yang sama.
4. Lakukan hard refresh browser setelah pembaruan.
5. Admin dan backend tidak perlu diperbarui untuk perubahan ini.

CATATAN DOKUMEN:
Contoh Berita Acara RAT adalah template umum dengan kolom isian. Sesuaikan isi, agenda, keputusan, dan pengesahan dengan peraturan organisasi serta hasil RAT sebenarnya.
Buku Pedoman Kegiatan PORSENI 2026 belum tersedia pada berkas yang diberikan. Setelah file PDF/DOCX resmi dikirim, tautannya dapat diaktifkan pada daftar DOCS di index.html.

CATATAN DENAH:
Bagian Denah Lokasi & Rincian Tempat saat ini berupa area siap isi. Peta lokasi belum ditampilkan karena daftar venue/ruang belum diberikan, sehingga tidak ada lokasi yang dikarang.
